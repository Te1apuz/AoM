# AoM artifact bot

Telegram-бот для Age of Magic: распознаёт созвездия артефакта со скриншота и
подбирает героев по таблице RedCat «Артефакты AoM».

Дизайн: `../docs/superpowers/specs/2026-10-25-hero-picker-design.md`.

## Как пользоваться

1. Прислать скриншот карточки артефакта (лучше файлом, без сжатия) или 4
   буквы созвездий текстом: `L G E B` (можно строчными и кириллицей).
2. Бот показывает буквы и кнопки типа: Массовая · Одиночная · Мульти ·
   Контратака · Вспомогательная.
3. После нажатия — герои по совпадению букв (4/4, 3/4, 2/4, по 3) и 5 героев
   под перековку. «Все N/4 (…)» выводит группу целиком в том же порядке.

`/refresh` — перезагрузить таблицу (только для id из `AOM_ADMIN_IDS`).

## Запуск

Из папки `bot/`:

```sh
AOM_ADMIN_IDS=123456789 python3 -m aom_bot ~/.config/aom-bot/token ~/.cache/aom-bot
```

- `token_file` — файл с токеном бота (не коммитить).
- `cache_dir` — сюда сохраняется последняя загруженная таблица
  (`heroes.xlsx`); если Google недоступен, бот отвечает по ней с пометкой даты.

## Данные

Живая таблица RedCat, выгрузка без авторизации:
`https://docs.google.com/spreadsheets/d/18IWMCIs8q2usE4HzB9enjbVJ6C1YLw50/export?format=xlsx`.
Перечитывается раз в 6 часов. Тип навыка хранится только цветом заливки,
поэтому читается сам xlsx со стилями.

## Тесты

Из корня репо:

```sh
python3 -m unittest discover -s bot/tests -t bot -v
```
